# Calculadora de consumo Energético - Energy Consumption Calculator
## Um projeto voltado para calculo de consumo energético de seus eletrodomésticos - A project focused on calculating the energy consumption of your home aplliances =)
---

### Idealização do projeto - Project conception
O projeto foi inicialmente idealizado por uma atividade do meu curso de Desenvolvimento de Sistemas, onde o foco principal era, mediante exempos deixados pelos professores, criar uma código em Python para o calculo de cosnumo de energia de eletrodmésticos.

*The project was initially conceived as an activity in my Systems Development course, where the main focus was to create Python code for calculating the energy consumption of household appliances, using examples provided by the professors.*

Foram passadas os objetivos do projeto, e o que deveriamos alcançar com o código, e após revisar o conteúdo e utilizar de agentes de IA para fazer uma varredura no código base e estudar possiveis implementações, cheguei a esta primeira versão.

*The project objectives and what we should achieve with the code were presented, and after reviewing the content and using AI agents to scan the codebase and study possible implementations, I arrived at this first version.*

### O que o código faz? - What the code do?
O código pega três principais *inputs* do usuário, sendo eles: Nome do eletrodoméstico, a potência em Watts do aparalho que quer consultar, a média de horas que o aparelho fica ligada por dia.

*The code takes three main inputs from the user: the appliance's name, its wattage, and the average number of hours the appliance is on per day.*

Com essas informaçõe so código retorna um resultado em texto, aplicando as informações já passadas como *input* e o resultado dos calculos gerados, dividindo-o em três categorias para melhor classificação do consumo, sendo elas: Consumo por dia, semana e mês, obetendo um panorâma geral daquele eletrodoméstico.

*With this information, the code returns a text result, applying the previously entered inputs and the results of the generated calculations, dividing it into three categories for better classification of consumption: daily, weekly, and monthly consumption, obtaining a general overview of that appliance.*

### O que foi feito de diferente? - What was done differently?
A instrução principal era a de fazer um código que apenas calculasse o consumo dos eletrodomésicos, com uma pequena dica de aplicar uma função que mostrasse tambem o valor em R$ gerado pelo consumo.

*The main instruction was to create code that only calculated the energy consumption of household appliances, with a small suggestion to also include a function that displayed the monetary value (in Brazilian Reais) generated by that consumption.*

Ao decorrer do código fiz implementações básicas para corrigir pequenas quebras de código, sendo elas:

*Throughout the code development, I made basic implementations to correct minor code breaks, namely:*

- **Opção de realizar mais consultas** - Ao fim da consulta o código encerrava, tendo que ser reiniciado sempre que quiser realizar uma nova consulta, assim, implementei um *input* ao final de cada consulta para que o código pudesse ser realizado repetidas vezes para diferentes eletrodomésticos / ***Option to perform multiple queries*** - *At the end of each query, the code would terminate, requiring it to be restarted each time a new query was desired. Therefore, I implemented an input at the end of each query so that the code could be executed repeatedly for different appliances.*

- **variaveis das opções de SIM e NÃO** - Adicionei mais de uma forma para concordância da função de realizar mais consultas, assim, o usuário não ficara preso a apenas uma palavra específica de reinicializar o código, evitando uma quebra do mesmo causada por falta de contexto / ***Variables for YES and NO options*** - *I added more than one way to agree on the function to perform more queries, so the user will not be stuck with just one specific word to reset the code, avoiding code breakage caused by lack of context;*

- **Limite de valores/horas** - Foi adicionado um limite de valores para o *input* de horas em que o aparelho fica ligando, sendo o mínimo de 1 hora, e o máximo de 24 horas, sendo adicionado tambem um *print* específico para cada uma das situações em que o usuário saia da linha de pensamento do calculo / ***Value/Hour Limit*** - *A limit has been added to the input of hours the device remains on, with a minimum of 1 hour and a maximum of 24 hours. A specific print has also been added for each situation where the user deviates from the calculation's train of thought.*

- **Tentativas de código** - Como politica pessoal na criação de códigos, utilizei **Agentes de IA** e meus próprios conhecimentos sobre UI/UX Design e fiz inumeras tentativas de quebrar o código, utilizando e ambiguidades, valores fora do padrão, consultas sem razão apropriada e uma sequência exponencial de consultas para avaliar a estrutura do código e encontras suas falhas.  Após a análise do código por completo, utilizei por meio do próprio *VsCode*, junto ao *Copilot* formas e correções que poderiam ser feitas, estudando as respostas fornecidas pelo agente e agregando conforme a necessidade / ***Code Attempts*** - *As a personal policy in code creation, I used **AI Agents** and my own knowledge of UI/UX Design and made numerous attempts to break the code, using ambiguities, non-standard values, queries without appropriate reason, and an exponential sequence of queries to evaluate the code structure and find its flaws. After analyzing the code completely, I used Vs Code itself, along with Copilot, to find ways and corrections that could be made, studying the answers provided by the agent and adding them as needed.*
