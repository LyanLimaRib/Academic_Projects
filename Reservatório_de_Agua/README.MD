# Nível do reservatório - *Water reservoir level*
## Consulte a lista correspondente ao nível do reservatório de água - *Consult the list corresponding to the water reservoir level.*

---
O projeto segue sendo um atividade acadêmica mais simples, agora trabalhando com mais bibliotecas presentes na linguagem Pyhton, sendo a desse projeto a biblioteca COLORAMA, responsável por fazer alterações visuais no código.

O projeto possui uma estrutura simples, mas que já consegue demonstrar sua capacidade de estilisar um programa, sendo de grande ajuda para projetos que possuem listas com pré definições, onde é possível fazer um distinção com mais clareza quando combinada com o COLORAMA

### O que o codigo faz? - *What the code do?*
---
O código tem apenas dois inputs principais, sendo eles - *The code has only two main inputs, which are:*:

- A oportunidade do usuário fazer um consulta - *The opportunity for the user to make a query.*;
- A seleção do nível do reservatório atual - *The selection of the reservoir level acts*;

Quando o usuario segue afirmando a solicitsação de um consulta, o código exibe a lista demonstrando os possíveis niveis do reservatorio, sendo 1 o mais baixo (Apresentando um nível critico de agua - representado pela cor Vermelha), e o nível mais alto sendo 5 (Apresentando um momento de atenção pelo nível elevado de água apresentado no reservatório - representado pela cor azul)

*When the user continues to request a query, the code displays a list showing the possible reservoir levels, with 1 being the lowest (showing a critical water level - represented by the color red), and the highest level being 5 (showing a moment of attention due to the high water level in the reservoir - represented by the color blue).*

Após a consulta inicial, o segundo input pede para o usuário inserir o nível atual de agua, retornando uma das opções presentes na lista, e encerrando o programa logo em seguida

*After the initial query, the second input prompts the user to enter the current water level, returning one of the options from the list, and then terminating the program.*
